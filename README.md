# 臺灣民事實務工具

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Chrome MV3](https://img.shields.io/badge/Chrome-Manifest%20V3-4285F4?logo=googlechrome&logoColor=white)](manifest.json)

專為**臺灣民事訴訟與債權實務**設計的瀏覽器擴充套件（Manifest V3）。整合金額速算、裁判費試算、救濟期間、日期工具、遲延利息與車輛修復費折舊試算，支援**彈出視窗**與**側邊面板**，方便一邊查閱資料一邊計算。

> **Taiwan Civil Practice Tools** — A Chromium extension for litigation math, court fees, remedy deadlines, dates, default interest, and vehicle-repair depreciation.

## 功能概覽

| 模組 | 說明 |
|------|------|
| **速算．裁判費** | 多行算式即時加總（含分數顯示）；依民訴法第 77 條之 13 試算一審／上訴裁判費（新舊制費率可切換） |
| **救濟期間** | 就審、上訴、抗告、再審末日試算；內建在途期間、送達生效、國定假日順延 |
| **日期計算** | 區間天數（含扣除區間）、日期加減推算、年齡與成年日（含民法第 12 條過渡期） |
| **利息計算** | 多本金群組、分段年息、遲延利息試算、列印明細、一鍵帶入裁判費 |
| **折舊計算** | 車輛修復費定率遞減法折舊試算，可產生書狀草稿 |

## 系統需求

- **瀏覽器**：Google Chrome（建議最新穩定版），或支援 Manifest V3 側載的 Chromium 瀏覽器（如 Microsoft Edge）
- **網路**：救濟期間之假日順延需自 [jsDelivr](https://cdn.jsdelivr.net/) 載入 [taiwan-holidays](https://github.com/imsyuan/taiwan-holidays) 資料；無法連線時改以週六、週日判斷並顯示提示

## 安裝

1. 取得專案至本機：
   ```bash
   git clone https://github.com/LexDev-tw/Civil_Calc.git
   ```
   或於 GitHub 下載 **Source code (zip)** 並解壓縮。
2. 開啟擴充功能管理頁：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 開啟 **開發人員模式** → **載入未封裝項目** → 選擇含 `manifest.json` 的專案資料夾。
4. 修改程式後，於擴充功能卡片按 **重新載入** 即可更新。

**權限**：僅使用 `storage`（側邊面板狀態）、`sidePanel`（側邊面板），以及對 `cdn.jsdelivr.net` 的存取（假日資料）。不讀取網頁內容，不蒐集使用者資料。

## 使用方式

- **彈出視窗**：點擊工具列圖示開啟。
- **側邊面板**：點右上角釘選圖示固定至側邊；切換時保留算式、裁判費金額、費率版本與目前分頁（經 `chrome.storage.local`）。
- **日期輸入**：各分頁日期欄位支援民國 7 碼（如 `1140101`）或西元 8 碼（如 `20250101`），亦可點日曆圖示使用原生日期選擇器。
- **複製**：多數計算結果可點擊複製；算式與金額區亦有專用複製按鈕。

## 各模組說明

### 速算．裁判費

- **多行算式**：每行支援 `+ - * /` 與括號；輸入時自動千分位；純分數行（如 `3/4`）加總時以最簡分數顯示，否則以小數（四捨五入至 2 位）或整數顯示。
- **裁判費**：輸入訴訟標的金額後即時計算一審與上訴費用；可切換 **114 年 1 月 1 日起新制** 與 **113 年 12 月 31 日前舊制**；「帶入上方計算結果」可將速算總額寫入標的金額欄。

**新制費率摘要**（民訴法第 77 條之 13，114.01.01 起訴訟行為適用）

| 標的金額級距 | 費率 |
|-------------|------|
| 10 萬元以下 | 基本費 1,500 元 |
| 逾 10 萬～100 萬 | 每萬元 130 元 |
| 逾 100 萬～1,000 萬 | 每萬元 117 元 |
| 逾 1,000 萬～1 億 | 每萬元 88 元 |
| 逾 1 億～10 億 | 每萬元 77 元 |
| 逾 10 億 | 每萬元 66 元 |

舊制基本費 1,000 元，各級每萬元費率較新制低（詳見 `popup.js` 之 `FEE_SCHEDULE`）。逾萬元部分無條件進位至萬元；上訴裁判費 = 一審 × 1.5，元以下捨去。

### 救濟期間

末日 = 收受日 + 不變期間 (A) + 在途期間 (B) + 送達生效 (C)；末日遇假日順延至下一工作日。

| 類型 | 不變期間 (A) |
|------|----------------|
| 就審 | 5 或 10 日（可切換） |
| 上訴 | 20 日 |
| 抗告 | 10 日 |
| 再審 | 30 日 |

- **在途 (B)**：依原審法院與住居所（含國外、大陸港澳）及管轄區內對照表計算；就審期間或訴訟代理人居住法院所在地者為 0 日。
- **送達 (C)**：一般 0 日；寄存 10 日；首次國內公示 20 日；首次國外公示 60 日；再次公示 1 日。
- 原審法院選擇會記憶於 `localStorage`（鍵名 `civilCalc_court`）。

### 日期計算

1. **區間**：起迄日均計入；可新增多段「扣除區間」計算淨天數。
2. **推算**：自基準日加減年、月、日（回推含當日、起算含當日）。
3. **年齡**：顯示目前年齡、成年日（含 112.01.01 民法第 12 條修正過渡）、滿 65 歲日。

### 利息計算

- 可建立多個**本金群組**，每組可有多段**計息期間**（計息本金、起迄日、年息）。
- 利息依期間折算年數計算：`本金 × 年利率 × 年數`（含不足一年之按日比例）。
- 完成輸入後，期間列顯示折算年數與該期利息；底部顯示請求金額合計、總利息與請求總額。
- **列印明細**可開啟試算表；**帶入裁判費**將請求總額寫入速算分頁之標的金額。

### 折舊計算

針對**車輛修復費**之零件（應折舊）與工資、烤漆、鈑金、其他（不折舊）分項輸入，依行政院固定資產耐用年數／折舊率表以**定率遞減法**試算，並產生書狀用說明草稿。

| 類型 | 耐用年數 | 折舊率（千分比） |
|------|---------|-----------------|
| 機車 | 3 年 | 536‰ |
| 運輸業客貨車 | 4 年 | 438‰ |
| 非運輸業客貨車 | 5 年 | 369‰ |
| 自訂 | 使用者輸入年數 | 依年數推算 |

零件折舊受殘值（原價 1/10）限制；出廠年月可輸入 `YYYYMM` 或完整日期。

## 法規與資料依據

| 項目 | 依據 |
|------|------|
| 裁判費（新／舊制） | 民事訴訟法第 77 條之 13 |
| 上訴裁判費加徵 | 民事訴訟法第 77 條之 16 |
| 上訴／抗告／再審不變期間 | 民訴法第 440、487、500 條 |
| 就審期間 | 辦理民事訴訟事件應行注意事項第 16 點 |
| 在途期間 | 民訴法第 162 條、法院訴訟當事人在途期間標準 |
| 送達生效 | 民訴法第 138、152 條 |
| 假日順延 | 民訴法第 163 條、民法第 122 條 |
| 成年年齡 | 民法第 12 條（112.01.01 修正施行） |
| 車輛折舊 | 固定資產耐用年數表、折舊率表 |
| 國定假日 | 行政院人事行政總處辦公日曆表（經 taiwan-holidays／jsDelivr） |

完整在途對照表與運算實作見 `popup.js`。

## 技術說明

- **Manifest V3**，純前端（`popup.html` + `popup.js`），無 npm、無建置步驟
- 算式：遞迴下降解析器；分數顯示採連分數近似
- 裁判費：逐級累加（`Math.ceil` 進位至萬元）
- 假日：CDN 載入並快取；失敗時僅判斷週末
- 分頁狀態：`localStorage`（`civilCalc_activeTab` 等）；側邊面板：`chrome.storage.local`
